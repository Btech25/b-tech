# B-TECH contact card

Open `public/index.html` to view the website. Open `edit-profile.html` to change your photo and contact details without editing code. Download the updated config.js and replace public/config.js. Publish the updated site to make changes visible to customers. Editing the local form does not change the online page automatically.

All customer-facing copy is in English. WhatsApp uses https://wa.me/212675644660. Service links add an English inquiry message. Save Contact downloads a standard vCard that the visitor can open in their Contacts app.

Your supplied portrait and logo are included. Demo videos, sample project galleries and empty social links from the original script are omitted. No customer data is collected. The editor is local only and is not included in the published public folder.

The site uses plain HTML, CSS and JavaScript. The standard Sites initializer failed on this Windows installation because its @clack/prompts dependency could not resolve; the static implementation requires no dependencies or build step.

Before printing a QR code or programming an NFC card, use the final publicly accessible URL. The btech.ma address in the original script has not been configured or verified.
